아래 대시보드 지표, 리스크, 웨이브 계획을 바탕으로 경영진 보고용 Markdown 초안을 작성하라.

구성: `## 요약`(3줄 이내) → `## 현황`(표 1개: 지표/값) → `## 주요 리스크`(상위 5건, 대응 방안 포함) → `## 일정과 웨이브` → `## 의사결정 요청`(결정이 필요한 사항 최대 3개).

- 입력에 없는 수치는 만들지 않는다. 데이터가 비어 있으면 "데이터 없음"이라고 쓴다.
- "가상 데이터"로 표시된 항목은 보고서에도 "(가상 데이터)"로 표기한다.
- 영향도 점수는 의사결정 보조 지표이며 단계 게이트는 체크리스트와 테스트로 판정한다는 점을 한 문장으로 덧붙인다.
- 마지막 줄에 "AI 초안 – 검토 필요"를 적는다.
